# Superseded campaign records

These are the ledger and session logs of a primary matrix that completed
**1620 of 1620 VALID** at commit `1b2dd83`, and was then discarded — not because
of anything it measured, but because the campaign driver's pre-flight cleanliness
check had to be corrected afterwards and the whole campaign is better executed
under a single commit than under two.

**No result from that matrix was examined before it was discarded.** Nothing was
inspected, ranked or compared; the decision rests only on wanting one frozen SHA
across the primary and sensitivity campaigns.

The raw output is not kept, because it is superseded rather than invalid and the
replacement is a complete rerun of the same conditions with the same seeds. The
ledger is kept so the attempt remains on the record.

See also `docs/experiments/amendments/AMEND-0001-resource-record-defect.md`, which
covers an earlier, genuinely defective attempt.
