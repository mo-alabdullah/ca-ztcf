# Protocol amendments

The final experiment protocol is frozen. If a correction becomes unavoidable, it
is recorded here as a separate file rather than by editing the protocol, so that
what was decided before the campaign stays legible next to what changed and why.

One file per amendment: `AMEND-NNNN-<slug>.md`, containing the UTC timestamp, what
changed, the reason, and which runs it invalidates. An amendment is committed
before the affected runs are repeated.

Empty is the expected state.
